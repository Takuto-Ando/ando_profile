# 管理者ページの設定と保護範囲（ローカル専用）

公開サイトのfooterに「管理者ページ」を追加する。
`/admin/` はパスワード入力画面、復号後に資料一覧を表示し、個別資料を開く。
「資料一覧へ」で戻り、別の資料を再入力なしで閲覧する。「ロックする」で全資料を破棄する。
`assets/private/content.json` はタイトル・一覧・全本文をまとめた暗号文のみ。
初期状態では資料未設定として何も開かない。
解除後の一覧には「FAE Design Win Simulator」の起動リンクも表示する。
リンク先は同じ端末の `http://127.0.0.1:4178/`。別端末で動くアプリには接続できない。
Simulatorは別途WSLで起動する。アプリ原本のREADMEと画面内の起動手順を参照する。
Simulator本体・Notion事例・回答履歴をこのサイトや暗号化資料へコピーしない。
この起動カードのHTMLは公開されるが、画面上は解除後だけ表示する。リンクの非表示をアプリの認証とは扱わない。
この説明と暗号化ツールは、既存の `scripts` build除外設定により公開しない。

## 資料とパスワードを設定する

ando_profileディレクトリで実行する。

```bash
python3 -m http.server 8766 --bind 127.0.0.1
```

1. `http://127.0.0.1:8766/scripts/protect-private-page.html` を開く。
2. 保護するHTMLを複数選ぶ。今回の資料は `Research_project/TI_job/outputs/ando_research_ti_fae.html`。一覧タイトルはHTMLのtitleから取得する。
3. 8文字以上のパスワードを設定する。推測されにくい20文字以上を推奨し、他サービスと使い回さない。短い数字のみのパスワードはオフライン推測に弱い。
4. 暗号化し、`content.json` をダウンロードする。
5. ダウンロードしたJSONで `ando_profile/assets/private/content.json` を置き換える。
6. `bash scripts/preview-poc.sh` で起動し、`http://127.0.0.1:4000/admin/` で正しいパスワード・誤ったパスワード・ロックを確認する。
7. 公開前にGit差分を確認する。今回の原本HTMLとパスワードはGitに追加しない。

この操作はpushや公開を行わない。サーバーは確認後にCtrl+Cで停止する。
資料を更新する場合も同じ手順で再暗号化する。
追加・更新するときは、最初に既存の `assets/private/content.json` を選び、同じパスワードと追加するHTMLを入力する。
同名HTMLは置き換え、それ以外は追加する。既存JSONを選ばない場合は新しい一覧を作り直す。
パスワード変更は既存JSONを選ばず、全ての原本HTMLを再選択して行う。
上限は100件、暗号化前のJSON全体で32MiB。gzip圧縮後に暗号化する。旧形式の非圧縮・単一HTML暗号文も閲覧・取込可能。
自作の信頼する教材だけ「検索・クイズ機能」を有効にする。スクリプトは同一origin権限のないsandbox内で実行する。外部通信は禁止、localStorage/sessionStorageは資料内のメモリのみで、閉じると学習履歴を消去する。
教材間の相対HTMLリンクは資料庫内の同名HTMLへ移動する。未登録の原本リンクは無効化し、外部HTTPリンクは別タブで開く。

## 保護の範囲

- AES-256-GCM、PBKDF2-SHA256（600000回）、毎回ランダムな16byte saltと12byte IV。
- パスワード・復号鍵・平文をlocalStorage、sessionStorage、Cookieへ保存しない。
- 復号本文はsandbox iframeへ表示する。標準では原本スクリプトを無効化し、信頼する自作教材だけnonce付きで許可する。外部画像・CSS・通信は常に禁止。外部リンクは明示クリック時のみ別タブで開く。
- 資料の高さとページ内移動は専用bridgeで親へ通知する。送信windowと資料ごとに変わる識別子を照合する。内部スクロールを使わず、操作欄は本文と一緒にスクロールする。
- 本番資料庫には研究・FAEキャリアHTMLと既存のTI学習HTML17件を登録。セミナー、PSDS、産業FAE、ブロック図、製品暗記、分類、Learning Lab、クイズ、市場・組織比較を含む。原本はResearch_projectのTI_job/outputsとti_block_diagramsに保持し、このrepoには暗号文のみを置く。
- 画像はdata URL、CSSはHTML内へ含める。今回のHTMLはそのまま使用できる。
- 暗号文・入力画面・管理者リンクは公開される。サーバーの本人認証やアクセス回数制限はない。長いパスワードが必要。
- 取得済み暗号文の失効はできない。パスワード変更でも過去の暗号文を回収できない。
- 元HTMLを公開repoへ置くと、暗号化してもGit履歴から読める。機密資料・認証情報・顧客データの保管には使用しない。
